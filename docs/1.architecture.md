# TodoList Application Architecture

## Overview
This is a modern .NET 9 Blazor Server application implementing a TodoList management system with enterprise-grade infrastructure and deployment capabilities.

## Architecture Type
**Monolithic Single Service Architecture** - The application is designed as a single, self-contained service that includes:
- Blazor Server frontend components
- REST API endpoints
- MCP Protocol support for AI integration
- Business logic and data access layers

## Technology Stack

### Backend Framework
- **.NET 9** - Latest .NET framework with enhanced performance and features
- **ASP.NET Core** - Web framework for building the application
- **Blazor Server** - Server-side rendering with real-time UI updates
- **Entity Framework Core 9.0** - ORM for database operations

### Database Strategy
- **Primary**: PostgreSQL 15 with Npgsql provider (production-ready)
- **Fallback**: SQLite (development and testing)
- **Dual Database Support**: Application automatically detects connection string and switches between PostgreSQL and SQLite

### Container Strategy
- **Single Container Deployment**: Monolithic application packaged in one Docker container
- **Multi-stage Docker Build**: Optimized with .NET 9 SDK for build and .NET 9 Runtime for production
- **Docker Compose**: Local development environment with PostgreSQL service

## Application Components

### Core Services
1. **TodoListService** - Business logic for todo item management
2. **TodoDbContext** - Entity Framework database context
3. **Health Checks** - Database and application health monitoring
4. **CORS Configuration** - Support for MCP client connections

### Frontend Components
- **Blazor Pages**: Interactive todo management UI
- **MainLayout**: Application layout and navigation
- **Error Handling**: Centralized error pages

### API Endpoints
- REST API for todo item CRUD operations
- Health check endpoints (`/health`)
- MCP Protocol support for AI assistant integration

## Database Schema
- **TodoItem Entity**: Core data model with properties for todo management
- **EF Core Migrations**: Database schema versioning and updates
- **Database Setup Script**: SQL initialization for PostgreSQL

## Testing Strategy
- **Unit Tests**: TodoListServiceTests covering business logic
- **Test Project**: Separate test assembly with MSTest framework
- **Isolated Testing**: Tests excluded from main application build

## Deployment Characteristics

### Containerization
- **Single Service Model**: One container for the entire application
- **Port Configuration**: Application runs on port 8080
- **Health Checks**: Built-in container health monitoring
- **Environment Variables**: Configuration through environment variables

### Infrastructure Requirements
- **Container Registry**: Azure Container Registry (ACR) for image storage
- **Database**: Azure PostgreSQL Flexible Server
- **Hosting**: Azure Container Apps (preferred) or Azure Kubernetes Service
- **Secrets Management**: Azure Key Vault for connection strings and sensitive data
- **Monitoring**: Application Insights integration ready

### Configuration Management
- **Environment-based**: Development, Production configurations
- **Connection Strings**: Supports both PostgreSQL and SQLite
- **User Secrets**: Development-time secret management
- **Application Insights**: Telemetry and monitoring configuration

## Security Considerations
- **Managed Identity**: For Azure resource access without credentials
- **Key Vault Integration**: Secure storage of database credentials
- **CORS Policy**: Configured for secure cross-origin requests
- **Health Check Security**: Monitoring endpoints for operational visibility

## Scalability Profile
- **Single Instance**: Designed for monolithic deployment
- **Database Connection Pooling**: EF Core with retry policies
- **Stateful Architecture**: Blazor Server maintains client state
- **Horizontal Scaling**: Suitable for Azure Container Apps scaling

## Development Workflow
- **Local Development**: Docker Compose with PostgreSQL
- **Testing**: Isolated unit tests with separate test database
- **Build Process**: Multi-stage Docker builds for optimization
- **CI/CD Ready**: Prepared for GitHub Actions automation

## Conclusion
This is a well-structured monolithic .NET 9 Blazor application suitable for deployment as a single container service to Azure Container Apps. The dual database support and comprehensive configuration make it flexible for various deployment scenarios while maintaining enterprise-grade standards for monitoring, security, and scalability.
