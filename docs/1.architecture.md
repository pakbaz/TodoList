# Architecture Overview

## Summary

- App type: ASP.NET Core (.NET 9) Blazor Server app with minimal APIs (MCP endpoints).
- Data: EF Core with primary provider PostgreSQL (Npgsql) and SQLite fallback.
- Containers: Dockerfile exposes 8080; docker-compose with PostgreSQL.
- Health: /health endpoint and container HEALTHCHECK.
- Telemetry: Application Insights in Production; plan to wire to Log Analytics.
- Tests: Unit test project present.

## Repository highlights

- App code: `Program.cs`, `TodoDbContext.cs`, `TodoItem.cs`, `TodoListService.cs`, components under `Components/`.
- Config: `appsettings*.json` with PostgreSQL `DefaultConnection` and SQLite `SqliteConnection`.
- Containers: `Dockerfile`, `docker-compose.yml` (postgres + app).
- Tests: `Tests/` folder.

## Runtime behavior

- If `ConnectionStrings:DefaultConnection` contains `Host=`, app uses Npgsql with transient fault handling.
- Else uses SQLite connection string or default `Data Source=todolist.db`.
- Health checks include DB context and self check; MCP endpoints under `/mcp`.

## Target Azure architecture

- Hosting: Azure Container Apps (ACA) in a Managed Environment (external ingress on port 8080).
- Registry: Azure Container Registry (ACR) to store images.
- Secrets: Azure Key Vault with system-assigned managed identity for the app; CI never handles raw secrets.
- Database: Azure Database for PostgreSQL Flexible Server.
- Observability: Log Analytics Workspace and Application Insights linked to ACA environment.

## Relationships

- CI builds/pushes image to ACR (tag = commit SHA).
- ACA pulls image via managed identity (AcrPull role on ACR).
- Key Vault stores `DefaultConnection` string; ACA consumes via Key Vault reference using MI (Key Vault Secrets User role).
- ACA environment streams logs/metrics to Log Analytics; App Insights connected to same workspace.

## Security

- OIDC GitHub→Azure for federation (AZURE_CLIENT_ID/SUBSCRIPTION_ID/TENANT_ID).
- ACA uses system-assigned MI; no embedded secrets.
- RBAC: AcrPull on ACR; Key Vault Secrets User on Key Vault for the ACA MI.

## Decisions

- Default deploy target: ACA (monolith, single container app).
- DB: Azure PostgreSQL (Npgsql present). SQLite remains for local development.
- Ingress: external with health probe `/health`.
- Images: immutable tags with `${{ github.sha }}`.
