# TodoList Application - Infrastructure Setup Instructions

## Prerequisites

### Required Tools and Access
- Azure CLI (latest version)
- GitHub CLI (for repository management)
- Docker (for local container testing)
- .NET 9 SDK (for application building)
- Azure subscription with appropriate permissions
- GitHub repository with OIDC authentication configured

### Azure Permissions Required
- Contributor role on the target subscription
- Key Vault Administrator role for secret management
- Network Contributor role for networking resources
- Container Registry Contributor role for ACR management

### GitHub Repository Configuration
- OIDC authentication configured with Azure
- Repository secrets: AZURE_CLIENT_ID, AZURE_SUBSCRIPTION_ID, AZURE_TENANT_ID
- Branch protection rules configured for main branch
- GitHub Actions enabled

## Infrastructure Deployment Guide

### Step 1: Repository Setup

1. Clone the repository and navigate to the project directory
2. Verify the infrastructure structure exists under `/infra`
3. Review parameter files for environment-specific configurations
4. Validate Bicep templates using Azure CLI

### Step 2: Parameter Configuration

Review and update the parameter files in `/infra/parameters/` for each environment:

**Development Environment (`dev.bicepparam`)**:
- Lower SKU sizes for cost optimization
- Simplified networking configuration
- Shorter backup retention periods
- Development-specific naming conventions

**Staging Environment (`staging.bicepparam`)**:
- Production-like configuration
- Full security implementation
- Standard backup retention
- Staging-specific naming conventions

**Production Environment (`prod.bicepparam`)**:
- High availability configuration
- Premium SKU sizes
- Extended backup retention
- Production naming conventions

### Step 3: Initial Azure Setup

Create the resource group and initial configurations:

```bash
# Set environment variables
export RESOURCE_GROUP_NAME="rg-todolist-prod"
export LOCATION="East US 2"
export ENVIRONMENT="prod"

# Create resource group
az group create \
  --name $RESOURCE_GROUP_NAME \
  --location $LOCATION \
  --tags Environment=$ENVIRONMENT Application=TodoList
```

### Step 4: Infrastructure Deployment

Deploy the infrastructure using Bicep templates:

```bash
# Deploy main infrastructure
az deployment group create \
  --resource-group $RESOURCE_GROUP_NAME \
  --template-file infra/main.bicep \
  --parameters infra/parameters/prod.bicepparam \
  --mode Incremental \
  --what-if

# Execute deployment after verification
az deployment group create \
  --resource-group $RESOURCE_GROUP_NAME \
  --template-file infra/main.bicep \
  --parameters infra/parameters/prod.bicepparam \
  --mode Incremental
```

### Step 5: Post-Deployment Configuration

After successful infrastructure deployment:

1. Verify all resources are created successfully
2. Configure additional security settings
3. Setup monitoring and alerting
4. Initialize the database schema
5. Configure application secrets in Key Vault

## Database Setup Instructions

### PostgreSQL Configuration

1. **Connect to the PostgreSQL instance**:
   ```bash
   # Get connection details from deployment outputs
   az deployment group show \
     --resource-group $RESOURCE_GROUP_NAME \
     --name main \
     --query properties.outputs.postgresqlFqdn.value
   ```

2. **Create application database and user**:
   ```sql
   -- Connect as administrator
   CREATE DATABASE todolistdb;
   CREATE USER todoapp WITH PASSWORD 'secure_password';
   GRANT ALL PRIVILEGES ON DATABASE todolistdb TO todoapp;
   ```

3. **Apply database schema**:
   ```bash
   # Run Entity Framework migrations
   dotnet ef database update --connection-string "Host=<fqdn>;Database=todolistdb;Username=todoapp;Password=<password>"
   ```

### Database Security Configuration

1. **Configure firewall rules** for necessary IP ranges
2. **Enable Azure AD authentication** for administrative access
3. **Configure backup and retention** policies
4. **Setup read replicas** for high availability (production only)

## Container Registry Setup

### ACR Configuration

1. **Login to Azure Container Registry**:
   ```bash
   # Get ACR login server from deployment outputs
   ACR_NAME=$(az deployment group show \
     --resource-group $RESOURCE_GROUP_NAME \
     --name main \
     --query properties.outputs.acrName.value -o tsv)
   
   # Login to ACR
   az acr login --name $ACR_NAME
   ```

2. **Build and push initial container image**:
   ```bash
   # Build Docker image
   docker build -t todolist:latest .
   
   # Tag for ACR
   docker tag todolist:latest $ACR_NAME.azurecr.io/todolist:latest
   
   # Push to ACR
   docker push $ACR_NAME.azurecr.io/todolist:latest
   ```

### ACR Security Configuration

1. **Configure managed identity access** for Container Apps
2. **Setup vulnerability scanning** with Microsoft Defender
3. **Configure geo-replication** for high availability
4. **Enable audit logging** for compliance

## Key Vault Configuration

### Secret Management Setup

1. **Retrieve Key Vault information**:
   ```bash
   # Get Key Vault name from deployment outputs
   KV_NAME=$(az deployment group show \
     --resource-group $RESOURCE_GROUP_NAME \
     --name main \
     --query properties.outputs.keyVaultName.value -o tsv)
   ```

2. **Configure application secrets**:
   ```bash
   # Set database connection string
   az keyvault secret set \
     --vault-name $KV_NAME \
     --name "ConnectionStrings--DefaultConnection" \
     --value "Host=<postgres-fqdn>;Database=todolistdb;Username=todoapp;Password=<password>;SSL Mode=Require"
   
   # Set Application Insights key
   az keyvault secret set \
     --vault-name $KV_NAME \
     --name "ApplicationInsights--InstrumentationKey" \
     --value "<instrumentation-key>"
   ```

### Access Policy Configuration

1. **Configure managed identity access** for Container Apps
2. **Setup RBAC permissions** for CI/CD service principal
3. **Configure audit logging** for secret access
4. **Setup secret rotation** schedules

## Container Apps Configuration

### Application Deployment

1. **Get Container Apps information**:
   ```bash
   # Get Container App name from deployment outputs
   APP_NAME=$(az deployment group show \
     --resource-group $RESOURCE_GROUP_NAME \
     --name main \
     --query properties.outputs.containerAppName.value -o tsv)
   ```

2. **Configure environment variables**:
   ```bash
   # Update Container App with Key Vault references
   az containerapp update \
     --name $APP_NAME \
     --resource-group $RESOURCE_GROUP_NAME \
     --set-env-vars \
       "ASPNETCORE_ENVIRONMENT=Production" \
       "ConnectionStrings__DefaultConnection=secretref:connectionstring" \
       "ApplicationInsights__InstrumentationKey=secretref:appinsights-key"
   ```

### Health Check Configuration

2. **Setup readiness probe** for traffic routing
3. **Configure startup probe** for application initialization
4. **Setup custom health check endpoints**
